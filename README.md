# TypeFlow – Typing Practice

Open `index.html` in any modern browser. No install or server needed.

1. Paste a paragraph, choose 5 / 10 / 15 minutes, press Start.
2. The paragraph sits on top, you type in the box below. The timer starts on your first key.
3. When time is up (or you press Finish) you get the full result report and an error review.

A word that is not a 100% exact match (spelling, case, punctuation) counts as an error.
Formulas: Words Typed = Keystrokes/5, Ignorable = 5% of Words Typed, Penalty = (Errors − Ignorable) × 10,
Gross WPM = Words/min, Net WPM = (Words − Penalty)/min, Accuracy = Net/Gross × 100.
